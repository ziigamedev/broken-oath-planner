# Broken Oath Planner

Fan-made build planner for Broken Oath (Crater Studios). Plan heroes, gear, skills, passive trees and loot filters from the game’s official public API.

Live site: https://broken-oath-planner.pages.dev

Data: Broken Oath public API. Not official, not affiliated with or endorsed by Crater Studios.
